# Jousting — локальная Fabric-адаптация

Minecraft 26.1.2, Java 25, Fabric Loader 0.19.5 и Fabric API 0.155.3+26.1.2.
Основана на оригинальном Jousting 1.0.12 автора stepsword. Лицензия оригинала — All Rights Reserved.

Собранный JAR из `build/libs/` устанавливается в `mods` на клиенте и сервере вместе с Fabric API. Для Rhongomyniad требуется также текущий Mahou Tsukai Fabric. Оригинальный NeoForge JAR рядом устанавливать не нужно.

Перенесены шесть копий, зарядка верхом, столкновения, урон, щиты, сбрасывание всадника, поза рук и параметры копий. Сядьте на ездовое существо, возьмите копьё в основную руку и удерживайте ПКМ во время движения к цели. Отпускание ПКМ прекращает зарядку.

Параметры находятся в `config/jousting-fabric.json`; сервер передаёт их клиенту при подключении. Автоматический импорт исходного NeoForge TOML и изменение настроек без перезапуска не реализованы.

Серверные проверки сравнивают шесть копий с запуском неизменённых оригинальных JAR: базовый урон, вес, прочность, длительность зарядки, скорость коня при зарядке и после отпускания. Полная проверка всех комбинаций транспорта, щитов, сетевой задержки и сторонних модов не завершена.
