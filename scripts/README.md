# Скрипты проекта

Канонический код находится в MahouTsukai-Fabric/src. Сборка выполняется
Gradle wrapper с JDK 25. runEconomyChecks — отдельный реальный серверный тест.

Повторяемые проверки: audit_jar.py, source_coverage.py, check_resources.py.
package_artifacts.py упаковывает текущие исходники, recovered, original,
документацию и уже собранные build/libs. Он не заменяет успешную сборку.
local_rcon.py обслуживает только локальный тестовый сервер; пароль не печатает.

port_*.py, add_doom.py и copy_economy_resources.py — исторические инструменты
первоначального извлечения/адаптации. Они НЕ являются полным генератором
проекта и могут перезаписать последующие ручные изменения. Для обычной
сборки и продолжения разработки их запускать не требуется.
prune_partial_textures.py изменяет только копии ресурсов текущей адаптации;
recovered и original остаются исходным материалом.
