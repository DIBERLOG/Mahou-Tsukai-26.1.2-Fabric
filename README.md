# Mahou Tsukai 26.1.2 — Fabric port

Неофициальный экспериментальный порт Mahou Tsukai **1.36.36** на **Minecraft 26.1.2 / Fabric**, текущая версия **0.25-incomplete**. Исходный автор Mahou Tsukai — **stepsword**. Пользователь сообщил о разрешении на портирование с сохранением авторства; отдельного документа разрешения в рабочем проекте нет. Оригинальная лицензия **All Rights Reserved** сохранена; этот репозиторий не предоставляет новую открытую лицензию на оригинальный код и ресурсы.

Перенесены оригинальные предметы, ритуальные семейства, сущности, интерфейсы и эффекты. Добавлено заклинание **DOOM**: чёрная дыра диаметром до 56 блоков, появление по прицелу, разрушение и урон игрокам/мобам, перезарядка пять минут. Установка и ограничения: [DOOM](MahouTsukai-Fabric/docs/DOOM.md).

## Проверки

- [15440 боевых случаев](MahouTsukai-Fabric/docs/COMBAT-COMPARISON-0.25.md): пары эффектов, сочетания защиты, удары предметами по игроку/мобу, расход ресурсов и выживание.
- [1372 сценария ритуальных катализаторов и сверка реестров](MahouTsukai-Fabric/docs/SCENARIO-COMPARISON-0.24.md): 53 ритуальных семейства, 87 записей предметов, 37 эффектов, 27 типов сущностей.
- [Ранее проверенные возможности](MahouTsukai-Fabric/docs/GAMEPLAY-0.24.md), [интеграции Jousting/Apotheosis](MahouTsukai-Fabric/docs/GAMEPLAY-0.23.md).

Полная эквивалентность во всех возможных ситуациях не заявляется. Матрица боя имеет описанные границы, Apotheosis проверен с конкретным неофициальным Fabric-портом, перенос мира следует выполнять на резервной копии.

## Сборка

Нужна **Java 25**. На Windows:

```powershell
cd MahouTsukai-Fabric
.\gradlew.bat build
```

Готовые JAR появляются в `MahouTsukai-Fabric/build/libs/` и `Jousting-Fabric/build/libs/`. Основной мод требует Fabric Loader 0.19.5 и Fabric API 0.155.3+26.1.2. Jousting — отдельное необязательное дополнение. Подробности: [README модуля](MahouTsukai-Fabric/README.md).

`build` включает локальные проверки; серверное сравнение с оригиналом запускается отдельно и требует самостоятельно подготовленных локальных эталонов. Оригинальные JAR, дубликат восстановленных исходников, тестовые миры, инструменты, личные вложения и сырые журналы исключены из Git.
