# Оружие Mahou Tsukai Fabric 0.21

Новый отдельный мир: `mahou-weapons-20261018`. Подключение к запущенному локальному серверу: `127.0.0.1:25585`, игрок `Player733`. Старый мир `mahou-port-test` сохранён отдельно. Мир находится в `MahouTsukai-Fabric/run/server/mahou-weapons-20261018`.

Включён творческий режим, выдано 1 000 000 маны. На панели быстрого доступа: Nobu, Mystic Staff, лук оружия, Treasury, Morgan, Caliburn, Clarent, Replica, Emrys. Остальное — в инвентаре. На площадке есть мишени; сундук слева содержит запас оружия, справа — обычное оружие для стрельбы, дальше справа — все 45 типов зарегистрированных свитков. Два экземпляра The Ripper нужны для парного использования. В инвентаре две книги «Оружие: стрельба» и «Оружие: способности» с краткими подсказками.

## Кнопки

ЛКМ — левая кнопка мыши, ПКМ — правая. Shift — присесть. F перекладывает выбранный предмет во вторую руку. Y — дополнительная способность/выбор заклинания; это латинская клавиша Y (физическая клавиша Н в русской раскладке). E открывает инвентарь, 1–9 выбирают ячейку панели. Действующие назначения можно посмотреть в «Настройки → Управление → Mahou Tsukai».

## Стреляющее оружие

| Предмет | Как использовать |
|---|---|
| **Nobu** | Держи ПКМ, наведи на мишень и, продолжая держать ПКМ, нажимай ЛКМ для выстрела. Shift+ПКМ переключает четыре режима: автоматический выбор целей, призыв у цели, круговой и линейный строй. Начни с исходного автоматического режима. Стрелки ↑/↓ меняют угол. Обычные патроны не нужны; расходуется мана. |
| **Mystic Staff** | Shift+ПКМ переключает большой взрыв, атаку по области и луч. В большом взрыве наведи на землю, держи ПКМ до завершения роста магических кругов, затем отпусти. Слишком раннее отпускание отменяет взрыв. Для области/луча удерживай ПКМ; следи за маной. |
| **Weapon Projectile Bow** | Стреляет оружием. Оставь обычный алмазный/железный меч в инвентаре; для явного выбора положи его во вторую руку через F. Возьми лук основной рукой, зажми ПКМ и отпусти, как обычный лук. Стрелы не подходят. Shift+ПКМ переключает обычные предметы и проекции; свежий лук находится в обычном режиме. Режим проекций требует подготовленной проекции. |
| **Treasury Projection Gauntlet** | Держи в инвентаре обычные мечи, возьми перчатку и удерживай ПКМ, глядя на мишень. Она выбирает подходящее оружие из инвентаря/эндер-сундука. Shift+ПКМ переключает прицельную стрельбу, цепи и атаку по области. Если рядом нет подходящего оружия или не хватает маны, стрельбы не будет. |
| **Morgan** | ЛКМ — обычный удар мечом. Удержание ПКМ основной рукой создаёт магический шар в направлении взгляда. Y включает ярость. Есть общий откат особых способностей Morgan/Caliburn. |
| **Staff Emrys** | Работает **во второй руке**. Выбери посох и нажми F, затем освободи основную руку. Удерживай ПКМ рядом с мишенями: после зарядки появляются молнии. Предмет с собственным действием в основной руке может перехватить ПКМ. |

Для первого опыта: выбери **Nobu в ячейке 1**, наведи на стоящего впереди моба, **держи ПКМ и нажми ЛКМ**.

## Мечи, кинжалы и остальные предметы

| Предмет | Как использовать |
|---|---|
| **Caliburn** | ЛКМ — удар. Y с мечом в основной руке запускает особую атаку; эффект зависит от допустимых целей вокруг и настроек. У исходного Caliburn есть специальное взаимодействие с нежитью. Это не оружие с обычным выстрелом ПКМ. |
| **Clarent** | ЛКМ — удар. Удерживай ПКМ основной рукой для блока и накопления силы от входящих атак. После прекращения длительного блока сила уменьшается по исходным правилам. Не стреляет. Неподвижные мишени не атакуют, поэтому накопление на них не увидеть. |
| **Replica** | ПКМ даёт ударную волну/отбрасывание и удерживает персонажа на месте. Shift+ПКМ без спринта сохраняет точку телепорта. Y без блока открывает настройки. Для телепорта удерживай ПКМ и нажми Y; нужна сохранённая точка, мана и отсутствие отката. ПКМ во время спринта запускает отдельный манёвр укрытия. |
| **The Ripper** | Положи один нож в каждую руку: выбери один, нажми F, затем выбери второй. ПКМ вызывает туман; с парой ножей также доступна невидимость. ЛКМ атакует, атака раскрывает невидимость и запускает её откат. |
| **Rule Breaker** | ПКМ активирует изменение вероятности и наносит владельцу небольшой урон по исходной механике; в творческом режиме обычный урон не ощущается. Shift+ПКМ меняет выбранное значение. Не стреляет. |
| **Dagger** | ПКМ вызывает кровотечение для начала ритуалов. Это ритуальный кинжал, не пистолет. Для создания круга используется M после подготовки кровотечения. |
| **Spatial Disorientation Staff** | Наведи на существо и держи ПКМ для пространственного воздействия. Если подходящее существо не выбрано, создаётся область в направлении взгляда/на выбранном месте. При отпускании действие меняется/завершается. |
| **Proximity Projection Keys** | Атакуй существо ЛКМ: при успешном попадании владелец переносится к цели. Это оружие ближнего боя, отдельного выстрела ПКМ нет. |
| **William** | Магическая книга, не обычное стреляющее оружие. ПКМ — чтение книги. Shift+ПКМ основной рукой размещает летающую книгу William и расходует этот экземпляр; её поведение связано с содержимым/известностью книги. В сундуке есть запасной экземпляр. |
| **Hammer** | Дополнительно выдан как инструмент для изготовления компонентов. Отдельного магического выстрела нет. |

## Mystic Code и First Sorcery

1. Возьми предмет и нажми **Shift+ПКМ**: откроются три ячейки для свитков.
2. Для простого опыта положи внутрь **Scroll of Gandr**. Свитки есть в инвентаре и сундуках.
3. Закрой окно, нажми **Y**, выбери загруженный свиток в круговом меню.
4. Наведи на мишень, **нажми и отпусти ПКМ** для применения. Для граничных ритуалов используется ПКМ по блоку.

First Sorcery управляется так же, но отличается правилами расходования/допустимых свитков. Пустой Mystic Code сам по себе не стреляет. Некоторые свитки запрещены в конкретном устройстве настройками.

## DOOM

Возьми Scroll of DOOM и нажми ПКМ, глядя на блок в пределах 96 блоков. В выбранной точке возникает чёрная дыра, подготовка длится **8 секунд**. Радиус разрушения блоков — **40**, поражения существ — **60**. Откат — **10 минут**. Испытывай вдали от площадки и сундуков: разрушение реально.

В выживании DOOM требует почти полного личного запаса маны, расходует 95% текущей маны и поражает игроков/мобов с учётом обычных защитных обработчиков и тотемов. Творческие игроки и наблюдатели не поражаются. В творческом режиме требования к мане обходятся, откат остаётся.

## Если ничего не происходит

- Проверь, что предмет в нужной руке, окно инвентаря закрыто, выбран правильный режим.
- Для Nobu нужен спуск ЛКМ при удержании ПКМ; для лука — меч; для Treasury — подходящее оружие; для Mystic Code — свиток внутри; для Emrys — вторая рука.
- Следи за сообщениями об откате. Творческий режим не отменяет все откаты и условия выбора цели.
- Пополнить запас: `/maxmahou Player733 1000000`. Вернуться на площадку: `/tp 0.5 201 -4.5`.
- Для проверки блока Clarent нужна атакующая цель: неподвижные мишени созданы с выключенным ИИ.

Инструкция сверена с текущими обработчиками предметов и назначениями клавиш сборки 0.21. Подготовка мира и выдача записаны в `analysis/manual-021-weapons-setup.log`, итоговый инвентарь и мана — в `analysis/manual-021-weapons-final-inventory.log`.
