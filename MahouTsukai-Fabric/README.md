## Зависимости и сборка

| Компонент | Зафиксированная версия |
|---|---|
| Minecraft | 26.1.2 |
| Java JDK | 25; проверено Eclipse Temurin 25.0.4.1+1 |
| Gradle wrapper | 9.7.0 |
| Fabric Loom | 1.18.4 |
| Fabric Loader | 0.19.5 |
| Fabric API | 0.155.3+26.1.2 |

Для Minecraft 26.1.2 используется `net.fabricmc.fabric-loom`, без Yarn и remapping.
Java 8 из системного PATH не подходит. Установите `JAVA_HOME` на JDK 25.

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-25'
.\gradlew.bat clean build
```

```sh
export JAVA_HOME=/path/to/jdk-25
./gradlew clean build
```

Сборки находятся в `build/libs/`. Файл с суффиксом `-sources.jar` содержит
исходники адаптированной части, а не всего оригинального мода. Весь восстановленный
код находится рядом с проектом в `../recovered/` и не включается в компиляцию.

`build` выполняет `portSelfCheck`: проверку NBT-сериализации данных маны,
прогресса и рецепта, исходных значений и сброса баффов. Дополнительно из корня:

```sh
python scripts/audit_jar.py
python scripts/check_resources.py
```

## Локальная установка

В отдельный экземпляр Minecraft 26.1.2 с Loader 0.19.5 положите Fabric API
0.155.3+26.1.2 и JAR `incomplete` из `build/libs/` в `mods/`.
NeoForge-версию одновременно не устанавливайте. Для тестов используйте новую
копию мира. Миграция данных из NeoForge attachments пока не реализована.

```powershell
.\gradlew.bat runClient
.\gradlew.bat runServer --args=nogui
```

Клиент и сервер используют разные каталоги `run/client` и `run/server`.
Для тестового сервера пользователь 15.10.2026 явно подтвердил принятие Minecraft
EULA. Тестовый сервер привязан к `127.0.0.1:25585`; локальный RCON — порт 25586.
Его случайный пароль и тестовый мир находятся только в игнорируемом `run/`.
Тестовый профиль может работать без online authentication для dev-клиента;
такие настройки предназначены исключительно для loopback-теста.

Настройки рабочего сервера Beget и Docker Compose не менялись. Linux/Docker,
Sodium, Iris и сторонний набор модов пока не проверены.
