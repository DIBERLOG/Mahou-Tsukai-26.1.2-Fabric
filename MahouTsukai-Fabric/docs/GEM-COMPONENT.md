# Данные маны самоцвета — fabric.0.4

Перенесены исходные GemMahou и CopyComponent. Native DataComponents регистрирует
тип `mahoutsukai:gem_mahou` с прежним полем `storedMana` (int) и прежним сетевым
форматом (четыре байта signed int). NeoForge DeferredRegister не используется.

GemData.get/set воспроизводит поведение исходных Utils.getGemMahou и
Utils.setGemMahou: отсутствующее значение инициализируется нулём, существующее
возвращается копией, изменение копии требует записи обратно в ItemStack.
Это необходимо, чтобы будущая зарядка не меняла разделяемый компонент другого
предмета. Подмена модели данных immutable-объектом не выполнялась.

**AttunedDiamond, AttunedEmerald и Attuner ещё не зарегистрированы.**
Их оригинальная зарядка вызывает полный PlayerManaManager.drainMana с поддержкой
батарей, роста максимума, стоимости и обновления инвентаря. Упрощённая зарядка
или выдача обычного алмаза под именем AttunedDiamond не добавлялись.

## Выполненные проверки

- Сборка main/client и автоматические проверки прошли.
- GemComponentCheck проверяет исходное нулевое значение, независимость копий,
  persistent codec с полем storedMana и точный сетевой int-формат.
- В standalone-проверке не утверждается проверка всей регистрации ItemStack:
  обычный vanilla bootstrap замораживает registry и требует отдельно привязанных
  item components. Проверки registry/persistence выполнялись в Fabric-сервере.
- Сервер зарегистрировал новый компонент без ошибок.
- В отдельном тестовом мире создан предмет-сущность vanilla diamond с явно
  заданным `mahoutsukai:gem_mahou={storedMana:4321}`. Это тестовый носитель
  компонента, а не реализация зачарованного самоцвета.
- Самая первая немедленная выборка не нашла сущность в только что загружаемом
  чанке; она не считается успешным тестом. После штатного сохранения и повторного
  запуска сервер нашёл предмет с прежним значением 4321. Это подтверждает
  фактическую запись и чтение persistent component через Minecraft.
- После проверки обе помеченные тестовые сущности удалены, добавленный для теста
  forceload ticket снят, сервер сохранён и штатно остановлен.
- Доказательства: analysis/gem-component-build.log, gem-component-checks.txt,
  gem-component-server.log и gem-component-restart.log.

Передача произвольного ItemStack с этим компонентом настоящему клиенту в этом
этапе отдельно не проверялась. Проверен непосредственно STREAM_CODEC; итоговая
интеграционная проверка будет выполнена с настоящими AttunedGem-предметами.
