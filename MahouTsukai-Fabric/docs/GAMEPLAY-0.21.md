# Обновление 0.21 — оружие от первого лица и Iris

Сохраняет возможности [0.20](GAMEPLAY-0.20.md). Клиент и сервер используют один JAR 1.36.36-fabric.0.21-incomplete.

Для активных Clarent, Replica и Treasury Projection восстановлено исходное преобразование руки: базовый сдвиг без дополнительного поворота стандартной анимации BLOCK. Изменение ограничено отрисовкой; игровая анимация предмета и обычный лук сохранены. Проверены обе руки и настоящий поток кадров.

При наличии Iris автоматически применяется исходный режим совместимости Mahou: стандартные частицы вместо собственного depth-shader тумана и отключение специальной обрезки Treasury. Дополнительные графические конвейеры Mahou регистрируются через публичный API Iris при фактической отрисовке, когда доступен расширенный формат вершин. Iris не является обязательной зависимостью.

- `analysis/phase021-normal-client-checks.txt`: настоящие модели/матрицы рук, Mystic Code/First Sorcery, живые кадры обеих рук, сброс поз, звук, GIF, модели, руководство из 101 страницы, JEI 18/40/7, Confusion, Bound, туман камеры и реальные GPU depth/uniforms без Iris.
- `analysis/phase021-shaderpack-client-checks.txt`: Iris 1.11.4 + Sodium 0.9.2, Minecraft 26.1.2, включённый Complementary Reimagined r5.9.3 LOW. Проверены живые кадры рук, позы моделей, автоматический режим совместимости и фактическая регистрация конвейеров, интерфейсы, GIF, модели, руководство, JEI и ввод. Ошибок Missing program mahoutsukai в финальном запуске нет.
- `docs/screenshots/0.21-doom-complementary.png`: настоящий кадр DOOM с активным пакетом. Проверка внешнего вида отдельно от серверной проверки разрушения/урона; вызов без владельца вдали от построек.
- `analysis/phase021-release-world.passed`: два запуска готового JAR с Fabric API, без JEI и служебных классов; копия настоящего NeoForge-мира, старый ID сущности, сохранение маны 321 и изменения Reality Marble между запусками. Хэши исходного мира не изменились. В маркере записан SHA256 проверенного JAR.

Проверки из отдельных source sets не входят в итоговый JAR. Временные Iris/Sodium удалены из тестового клиента после проверки, настройки пользователя восстановлены. Исходный мир пользователя не заменялся копией для миграционных тестов.

## Разобранные неудачные запуски

Первый тест звука обнаружил выключенную общую громкость пользователя: проверка теперь временно задаёт слышимую громкость и восстанавливает настройки. Первый настоящий запуск с пакетом выявил пропущенную регистрацию конвейеров Iris — исправлено. Прямой вызов отрисовщика руки вне прохода Iris оказался некорректным стендом: вместо него с пакетом проверяются реальные кадры. Одна попытка запуска Gradle завершилась системной ошибкой No buffer space available до запуска игры; повторный запуск успешен. Журналы сохранены.

В финальных dev-клиентах присутствуют ожидаемые ошибки профиля/Realms для тестового offline-пользователя. Complementary выводит предупреждения собственных выражений/сопоставлений блоков, включая BIOME_SULFUR_CAVES. Это не утверждение о полностью чистом журнале или проверке всех шейдерпаков.

## Что ещё ограничивает полную готовность

Основной набор оригинальных возможностей подключён: 81 ID предмета, 53 ритуальных семейства, 27 типов сущностей. Эти количества обозначают покрытие каталога и серверных сценариев, а не процент полного совпадения с оригиналом.

Jousting и Apotheosis для этой версии Minecraft доступны в проверенном каталоге только для NeoForge; соответствующие внешние интеграции в Fabric не подключены. Ответы официального API на 18.10.2026 сохранены в `analysis/phase021-optional-availability.json`.

Не подтверждены все ветви поведения/анимаций каждого оригинального заклинания, все комбинации сторонних модов и шейдерпаков, длительная игра 5–10 игроков и Linux. Поэтому отметка INCOMPLETE пока сохранена: эта сборка пригодна для локального тестирования, но универсальная 100% совместимость не заявляется.
