# Предметы и связанные системы — этап 0.16

В сборке зарегистрированы **81 из 81 оригинального предмета**. Все **53 из 53 ритуальных семейств** сохраняются. Проверены на сервере **25 из 27 оригинальных типов сущностей**; этот счёт включает снаряды и визуальные сущности. Числа относятся к отдельным каталогам, а не к проценту готовности всего мода.

В 0.15 уже были 74 предмета. В 0.16 добавлены последние семь:

## Использование

- Mystic Code: присесть + ПКМ открывает три ячейки свитков; удержание Y открывает выбор. Удержание/отпускание ПКМ применяет выбранное заклинание. First Sorcery расходует прочность вместо расходования свитка.
- Emrys применяется во второй руке. Получение: держать усиленную палку во второй руке при ударе молнии.
- Replica: удержание ПКМ блокирует; присесть при начале применения сохраняет точку. Y при блокировании открывает портал к этой точке; Y без блокирования открывает выбор запомненного урона. Для получения усиленный щит должен находиться в основной руке при блокировании; нужны броня, запас поглощённого Damage Exchange, души Death Collection и активный Immunity Exchange согласно исходным условиям.
- Nobu: присесть + ПКМ переключает четыре режима. ПКМ подготавливает/размещает конструкции, ЛКМ стреляет; стрелки вверх/вниз меняют угол пушек.
- William: положить усиленную написанную книгу на пустую кафедру. При первом использовании сервер загружает настроенные словари по HTTPS и сохраняет их в `mahoutsukai/dictionaries` игрового каталога. Без готового словаря оценка ожидает загрузки. Присесть + ПКМ с William выпускает летающую книгу; владелец может переключить театр приседанием + ПКМ по ней. Обычный ПКМ по книге возвращает предмет. Чтение другим игроком и торговля увеличивают известность с исходными ограничениями.

## Проверки

`build runEconomyChecks` проверяет прошлые игровые системы и новые предметы: оригинальное получение Emrys/Replica/Nobu/William, настоящее меню и вложенное хранение свитков, сохранение компонентов, Gandr/Fallen Down внутри Mystic Code, прочность First Sorcery, реальные попадания летящего Nobu, призыв/стрельбу пушек, реальный перенос через Replica, театр/ману/известность William и сохранение летающей книги.

В подключённом клиенте проверены загрузка семи моделей, руководство на 101 страницу, серверное открытие меню трёх свитков, отображение летающего William и прицеливание/заряд Nobu. Снимки находятся в `docs/screenshots/0.16-*.png`; журналы — в `analysis/`.

Исправлены обнаруженные ошибки: пропуск последнего слова словаря, равенство компонентов Fiction с авторским UUID, защита владельца меню от перемещения, сохранение владельца/режима портала Replica и UUID участников молнии. Nobu теперь начинает проверку столкновений сразу после выстрела: прежняя задержка пропускала близкие цели. Сетевые команды проверяют предмет, диапазон, режим, допустимые номера и принадлежность действий.

## Что ещё остаётся

Полное совпадение всех анимаций и шейдеров, часть общих интерфейсов/проекторов, два оставшихся оригинальных типа сущностей, сторонние интеграции и перенос существующих NeoForge-миров требуют отдельного завершения и проверки. В частности, полный эффект Abyss на мир, внешний shader clipping ворот Treasury и интеграции Apotheosis/Jousting не подтверждены. Наличие всех предметов не означает полного совпадения всех функций оригинального мода.

Дополнительный DOOM сохранён и не входит в оригинальные счётчики. Для клиента и сервера нужна одна и та же версия **1.36.36-fabric.0.16-incomplete**, Minecraft 26.1.2, Java 25, Fabric Loader 0.19.5 и Fabric API 0.155.3+26.1.2.
