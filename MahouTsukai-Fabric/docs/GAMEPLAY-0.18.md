# Совместимость и перенос миров — 0.18 INCOMPLETE

Это рабочая сборка для Minecraft 26.1.2 / Java 25 / Fabric Loader 0.19.5 / Fabric API 0.155.3+26.1.2. На клиент и сервер устанавливается одинаковый JAR. JEI необязателен; проверена Fabric-версия 29.47.0.111.

## Изменения

- Перенесены три оригинальные категории JEI: 18 рецептов кругов, 40 рецептов свитков/особых преобразований, 7 рецептов оружия. Сохранены специальные ингредиенты кругов и существ, рецепты Caliburn, Morgan, Clarent, Emrys и Replica. Открытие всех категорий подтверждено настоящим JEI runtime; выбранные экраны просмотрены и сохранены в `docs/screenshots/0.18-jei-*`.
- Перенесены Fear и Confusion: страх от Caliburn, прекращение атак и бегство мобов, дезориентация мобов, разворот управления игрока и запрет прыжка. Scrying снова использует оригинальный Confusion вместо ванильной тошноты. Присутствуют все 37 исходных типов эффектов и дополнительное имя для чтения прежнего Fabric cooldown.
- Добавлены `/mahoucancel`, `/clearfictions`, `/clearplayerfictions`, `/mahouset`, `/mahousummon`. Административные команды сохраняют проверку прав. Подкоманда призыва предмета Rhongomyniad выдаёт понятную ошибку, пока отдельный предмет Jousting недоступен; фиктивный предмет не создаётся.
- Работают `ONE_LIFE` и `BUFF_CLEAR_ITEMS`: оригинальный сброс магии при смерти и снятие магических усилений при завершении использования указанных предметов, по умолчанию молока.
- Полный набор имеющихся серверных параметров передаётся клиенту с проверкой типов/диапазонов без частичного применения. Нестандартные `LEY_DISTANCE=777` и `PROJECTOR_SIZE_CAP=13` проверены при настоящем сетевом подключении. Локальные настройки HUD/графики вынесены в `config/mahoutsukai-fabric-client.json` и не заменяются серверным пакетом; при отключении серверные значения сбрасываются.
- Сравнение с загруженным оригиналом обнаружило и исправило настройки по умолчанию: стоимость Rhongomyniad **300** (40 было значением статического поля до загрузки NeoForge-конфига), остановка вращения проектора, исключение Mending при Power Consolidation, исключения Caliburn/Morgan для Clarent и кэширование изображений. Ранее сохранённые явные настройки Fabric автоматически не переписываются.

## Перенос мира

Мод читает исходный контейнер `neoforge:attachments` для `player_mahou`, `living_mahou`, `settings_mahou`, `mahoujin_entity` и переводит `chunk_mahou` в `fabric:attachments`. При сохранении используются форматы Fabric. Уже существующие данные Fabric имеют приоритет, поэтому старый контейнер не откатывает более новый прогресс. Импортированные чанки помечаются для сохранения.

Восемь исходных имён сущностей поддерживаются как имена загрузки существующих реализаций Fabric. При повторном сохранении они получают действующий Fabric ID. Добавлены исходные `rpsw_cooldown` и `should_render`; старое имя cooldown из Fabric 0.17 также распознаётся.

Подготавливать нужно **отдельную копию остановленного мира**. Из корня проекта:

```powershell
python scripts/prepare_fabric_world.py "C:/путь/исходный-мир" "C:/путь/новая-копия-Fabric" --config "C:/путь/исходный-инстанс/config/mahoutsukai-server.toml"
```

Скрипт не перезаписывает существующее назначение и не изменяет исходный мир. Проверяет блокировку мира, копирует измерения/данные/чанки и переводит поддерживаемые настройки TOML в два Fabric JSON. Учитывает реальные имена ключей исходного конфига, включая отличающееся имя Fallen Down. При неподдерживаемом нестандартном параметре прекращает работу до копирования. Отчёт `mahoutsukai-migration.json` означает подготовку копии, а не успешный игровой запуск.

Без `--config` учитываются конфиг в соседнем `config/` и переопределение внутри `serverconfig/` мира. Для мира из папки `saves/` лучше явно указать конфиг исходного инстанса. Изменения других модов скрипт не преобразует. Обратная миграция Fabric → NeoForge не реализована.

Временные магические сущности могут не содержать данных, которых не сохранял сам оригинал: например, конструктор исходного Authority сохранял только временный числовой ID владельца. Не существовавшие в сохранении сведения восстановить нельзя.

Дополнительно выполнено [сравнение выбранных сцен с настоящим клиентом оригинала](VISUAL-COMPARISON-0.18.md). Исправлены плотность тумана камеры и цвета без шейдеров; обычные и проекторные частицы теперь используют общий путь мягкого тумана.

## Что не завершено

1. **Jousting и Apotheosis:** в проверенном каталоге версий для 26.1.2 доступны NeoForge-сборки. Их игровые API нельзя подключить в обычный Fabric. Сущность Rhongomyniad работает; отдельный предмет копья и его интеграционное получение не реализованы. Обработка самоцветов/аффиксов Apotheosis также не реализована. Эти моды не включены в JAR.
2. **Полное визуальное сравнение:** выполнен [частичный прогон настоящего клиента NeoForge](VISUAL-COMPARISON-0.18.md). Проверены круги и экраны проекторов, найдены и исправлены отличия тумана. Все позы брони, GIF, заклинания и старые режимы анимации ещё не сопоставлены.
3. **Конфигурационная полнота:** не все исходные переключатели представлены; часть относится к отсутствующим интеграциям или неактивным механизмам оригинала. Подготовка мира перечисляет такие настройки и отклоняет их нестандартные значения.
4. **Матрица окружений:** Sodium/Iris, сторонние сборки, Linux и длительная многопользовательская нагрузка отдельно не подтверждены.

По этим причинам сборка сохраняет обозначение INCOMPLETE. Числа 81/81 предметов и 53/53 семейств описывают каталоги, не общий процент готовности.
