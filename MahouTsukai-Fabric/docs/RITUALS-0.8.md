# Сборка 0.8: ритуальная основа и Geas

## Как получать оригинальные свитки

1. Скрафтить кинжал по исходному рецепту и нажать правую кнопку с ним:
   он наносит рану и даёт Bleeding. Белая шерсть + кинжал дают 4 ткани;
   кинжал после крафта возвращается.
2. Положить ткань на подходящую поверхность. С Bleeding посмотреть вперёд
   и нажать **M**: появится кровавый круг, ткань сохранится внутри него.
   Можно нарисовать круг без ткани для наземных ритуалов.
3. Нанести три исходных порошка, нажимая по кругу. Порядок не влияет на
   рецепт; число одинаковых порошков учитывается.
4. По готовому кругу с тканью нажать пустой рукой: выпадет привязанный
   к заклинателю свиток, круг исчезнет. Fae Essence рисует круг фей;
   его свитки имеют исходную общую привязку The Fae.

| Заклинание/круг | Три порошка | Обязательна ткань |
|---|---|---|
| Зрение фей | глаз + глаз + глаз | да |
| Вознесение | жемчуг Края + жемчуг Края + золото | нет; с тканью даёт свиток |
| Изменение вероятности | золото + алмаз + кварц | нет; с тканью даёт свиток |
| Geas | золото + изумруд + железо | да |

Пустой рукой по новому пустому кругу можно повторить последний рецепт:
порошки и при необходимости ткань берутся из инвентаря или сумок,
предоставляющих Fabric ItemStorage API. Конкретные модовые сумки ещё не
проверены. При отказе извлечения Fabric transaction откатывает изменения.

Наземное Вознесение проверяет сущности над кругом с исходным периодом 4 ticks,
переносит на верхнюю допустимую поверхность и оплачивается батареями/кастером.
Для получения Rule Breaker нужны минимум два круга изменения вероятности
с плодами хоруса над ними. Применить соответствующий свиток при достаточной
мане: 5000. Число подходящих кругов определяет modulus оружия; плоды расходуются.
Сохранены исходный поиск по чанкам и его границы, включая загрузку чанков.

## Что добавлено в код

MahoujinTileEntity, cloth/fay/caster/catalyst NBT и синхронизация, базовый круг,
SpellCloth, single-use circles, AboveChecker, ActiveCircleConfig, три первых
рецепта и затем Geas. Исходная геометрия/текстуры кругов и предмета mahoujin;
клавиша M и исходный KeyPressPacket с серверной проверкой Bleeding/поверхности.
Открытие магии выставляет исходный hasMagic и trigger mahoutsukai; добавлен
оригинальный root advancement. Дополнительные root/advancement ветви не перенесены.

Fae Essence теперь имеет исходное поведение рисования круга, а фея — исходный
loot table (1–2 essence с модификатором looting). Восстановлены рецепты обычной
Mana Circuit и ткани. При обычном получении магии феи могут появляться через
уже перенесённую ветку регенерации у сильных leyline; новых правил появления
в ванильных биомах эта версия не вводит.

Geas: исходные выбор цели по строгому ray/box пересечению и проверка непрозрачных
блоков, создание/удаление обета на тип существа, именованную цель или предмет;
запрет атаки, входящего урона от заклинателя и подбора предметов. Уникальные
неименованные обеты дают бонус регенерации. Сохранён MandatoryFun marker за
отменённый подбор. Сжигание выброшенного собственного Geas-свитка снимает обеты.
Удаление существующего обета тратит ману, но не расходует свиток — как в оригинале.

GameStages integration не перенесён. SPELL_BLACKLIST учитывает ID/namespace.
ActiveCircleConfig перенесён с исходными ограничениями и заменой старых активных
кругов. Остальные типы кругов/способностей не регистрировались как заглушки:
их механики пока не работают. DOOM остаётся отдельным дополнением пользователя,
его ритуальный рецепт пока не добавлен.

## Проверки

Серверный runEconomyChecks проверяет прежние экономику/DOOM и теперь также:
реальный M-key handler, порошки и преобразование блоков, cloth/caster NBT,
выдачу свитка, Fae Essence, повтор рецепта через Fabric storage сумки,
отсутствие расхода при нехватке ресурсов, требование ткани, наземное Вознесение,
создание Rule Breaker, native recipe/remainder ткани, исходный лут феи.
Geas проверен через полученный в ритуале свиток: выбор/стена, цена/расход,
создание/снятие, регенерация, атака/урон, pickup, именование и уничтожение огнём.
Журнал: ../../analysis/0.8-delivery-build.log (финальная clean build и все серверные проверки).

Клиент 0.8 подключился к local server; сохранён и осмотрен штатный снимок
screenshots/ritual-circles.png. Он подтверждает графику обычного, fae/cloth
и активного наземного круга. Снимок использует test-only VisualCapture через
встроенную Minecraft Screenshot; helper не входит в production JAR.

Теперь: 26 предметов, 8 блоков, 7 block entity types, 2 entity types;
128 recovered Java-файлов включены, часть файлов перенесена частично.
Число файлов не является процентом готовности. Большинство оригинальных
способностей, оружия и существ ещё впереди; Linux/Docker, Iris/Sodium,
модпак, GameStages и перенос старых NeoForge миров не проверены.
