# Исправление входа в Reality Marble — 0.35

Архимаг автоматически появляется при обычном входе в `mahoutsukai:reality_marble` через Reality Marble. `spawnFor` по-прежнему запрещает естественное появление вне этого измерения и повторно использует живого босса арены.

Исправлена привязка одиночного боя: если внешняя цель не выбрана, противником игрока становится появившийся босс. Обычный урон больше не завершает одиночный бой раньше времени. Выбранная внешняя цель сохраняет прежний приоритет.

Проверено: `runEconomyChecks build` прошли; регрессионный сценарий проверяет настоящий вход свитком, UUID появившегося босса, сохранение измерения на следующем серверном тике после обработчика урона и прежнее возвращение при явном завершении. Текущий реальный клиент также вошёл в измерение через обычную функцию заклинания; получен `BATTLE_REPLAY_REALITY_MARBLE` с живым боссом и совпадающим UUID противника.

`BattleReplay` и команда тестового возрождения находятся только в тестовых source sets, отсутствуют в выпускаемом JAR. Локальный повтор запускается через `runBattlePreview` и запрос `battle-replay.request` в каталоге тестового мира. Пользовательские предметы не заменяются.
