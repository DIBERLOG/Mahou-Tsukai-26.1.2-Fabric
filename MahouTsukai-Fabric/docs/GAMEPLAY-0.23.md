# 0.23 — Nobu и необязательные интеграции

## Изменения

Исправлены растянутые треугольники между пушками Nobu: отдельные TRIANGLE_STRIP в общем буфере Minecraft теперь разделяются вырожденными вершинами. Общая точка исправления охватывает собственную геометрию Mahou, сохраняя UV, цвет, освещение, нормали и порядок треугольников. Проверена сцена с десятью клиентскими GunEntity; временные сущности затем удалены. Снимок: `analysis/phase023-nobu-isolated.png`.

Добавлен отдельный локальный порт Jousting: шесть копий с исходными параметрами и механикой зарядки верхом. При его наличии Mahou регистрирует предмет Rhongomyniad, принимает копья в Treasury и превращает зачарованное копьё с владельцем в Rhongomyniad через исходное озеро консолидации. Без Jousting основной мод запускается самостоятельно. Настройки копий передаются сервером клиенту. Подробности установки и ограничения — `Jousting-Fabric/README.md`.

Восстановлено удаление самоцветов и аффиксов при расчёте консолидации через настоящий API Apotheosis. Проверенная среда: неофициальный Apotheosis Adventure Fabric **0.2.1-public**, Placebo Fabric **0.1.3**, Cardinal Components API **8.0.1**. Исходный предмет сохраняет компоненты до обычного потребления; очищается копия для расчёта. Более новая версия 0.5.2 не проверена: её набор зависимостей не подготовлен. Это проверка конкретной интеграции Mahou, а не всех возможностей стороннего порта Apotheosis.

Исправлено накопление старых модификаторов оружия на служебном игроке при расчёте урона для консолидации. Предыдущий предмет теперь снимает свои модификаторы перед установкой нового.

## Что ещё не доказано

Это не исчерпывающее совпадение каждого сценария с оригиналом. Серверные проверки покрывают конкретные сценарии, а регистрация предмета или сущности сама по себе не доказывает все её свойства. Нужны расширенные сравнительные сценарии PvP, транспорта и щитов Jousting, взаимодействий со сторонними защитами территорий, сетевых задержек, смешанных эффектов и длительной игры нескольких игроков. Автоматический импорт настроек Jousting из NeoForge TOML не реализован. Новое исправление геометрии проверено на обычном клиенте; проверка Iris/Complementary относится к предыдущей 0.21, повтор с новым исправлением ещё не выполнен.

Зелёные рунические линии и концентрические кольца из пользовательского снимка — Leylines, видимые при Fay Sight. Их рисует RenderLeyLines, только когда у наблюдателя есть FAY_SIGHT_EYES. Это узлы маны мира, а не атака стоящих рядом криперов.
