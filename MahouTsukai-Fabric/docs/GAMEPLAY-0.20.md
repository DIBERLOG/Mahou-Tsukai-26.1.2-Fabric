# Обновление 0.20 — позы оружия и рука Mystic Code

Сохраняет возможности [0.19](GAMEPLAY-0.19.md). Клиент и сервер используют один JAR 0.20.

Восстановлены исходные преобразования `RiflePose` для Nobu и `ClarentPose` для блокирования Clarent. Они выполняются внутри стандартного расчёта рук до последующего движения модели, как исходный NeoForge arm-pose hook. Nobu занимает обе руки; учтены ведущая левая рука и использование из второй руки. Clarent меняет только руку, которой используется основной предмет. Механика урона и серверные способности не менялись.

Для Mystic Code и First Sorcery перенесена исходная отрисовка руки от первого лица: кожа и рукав текущего игрока, зеркальные преобразования, взмах основной руки. При переходе на предмет отменяется старая модель основной руки, даже если ItemInHandRenderer ещё держит предыдущий предмет. Вторая рука сохраняет обычную отрисовку предмета.

Проверки `WeaponPoseChecks` в настоящем клиенте сравнивают координаты/углы с исходными формулами на моделях персонажа и брони, обе ведущие руки и обе руки Nobu. Проверяются извлечение состояния настоящего игрока, сброс после прекращения использования, отправка геометрии руки через настоящий ItemInHandRenderer, отмена старого предмета при переходе и восстановление стека матриц. Результат: `analysis/phase020-client-checks.txt`.

Кадры настоящего клиента: `docs/screenshots/0.20-nobu-pose.png`, `0.20-clarent-pose.png`, `0.20-mystic-hand.png`. Это игровые снимки Fabric; отдельный клиент оригинала в этом этапе не запускался.

Полная сборка и серверный набор: `analysis/phase020-final-checks.log`. Два запуска готового JAR с Fabric API на копии мира NeoForge: `analysis/phase020-release-world.passed`, включая SHA256 проверенного файла. Служебные клиентские проверки не входят в JAR.

Это не подтверждение полного визуального совпадения всего мода: специальные движения во всех состояниях, сторонние шейдеры и полная матрица оружия требуют дальнейшей сверки. Внешние интеграции Jousting/Apotheosis для NeoForge остаются неподключёнными в обычном Fabric. Сборка сохраняет отметку INCOMPLETE.
