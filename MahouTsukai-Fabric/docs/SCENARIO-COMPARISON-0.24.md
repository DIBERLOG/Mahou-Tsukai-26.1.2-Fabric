## Найдено и исправлено

Первый прогон сохранил 50 записей различий в `analysis/phase024-initial-scenario-differences.json`. Это количество полей/добавленных записей, а не 50 независимых ошибок.

- Восстановлены размеры 19 родных типов сущностей, в том числе Rhongomyniad, William, проекционных снарядов, пушек и ряда магических кругов. Для большинства этих кругов оригинал использует стандартные 0,6×1,8; прежний порт задавал 1×1 либо нулевой размер.
- Emrys снова возвращает исходную прочность `POWER_CONSOLIDATION_DURABILITY` через настоящий `ItemStack.getMaxDamage`, как другие перенесённые динамические виды оружия.
- Funbook снова допускает исходную стопку из 64.
- Проверка чисел приводит обе стороны к одинаковому JSON-представлению: это устраняет ложное различие между загруженным JSON `0.3` и внутренним Java `float`, оба записываемыми как `0.3`.

## Явные различия между загрузчиками

Оригинальный Nobu возвращает расширенное NeoForge-значение перечисления `MAHOUTSUKAI_CUSTOM`. Fabric использует `NONE` и отдельные native model/hand mixins. Оба конкретных значения проверяются; позы проверяются отдельно в клиенте. Это не утверждение, что необработанные значения перечислений одинаковы.

Fabric сохраняет восемь дополнительных ID вспомогательных сущностей для старых сохранений порта и дополнительный эффект перезарядки Replica. Они перечислены в `analysis/phase024-loader-adaptations.json`, исключены из счётчика оригинального содержимого и не заменяют требование наличия всех исходных ID. Пользовательский DOOM также не участвует в сравнении оригинала.

## Проверки только Fabric и границы выводов

Повторён существующий полный серверный набор: мана/регенерация, ритуальные семейства, оружие, существа, контракты, границы, глаза, души, Kodoku, проекции, измерение, проекторы, интеграции и DOOM. Его успех подтверждает заявленные проверки кандидата; он не означает, что вся эта программа без изменений исполнена в оригинале. Финальные PASS-строки после сокращения перезарядки — `analysis/phase024-five-minute-boundary.log` и `phase024-five-minute-base-direct.log`.

Исчерпывающее сравнение **всех возможных игровых сценариев не завершено**. За пределами нового прямого сравнения остаются полный перебор боевых результатов всех заклинаний, совместные эффекты и порядок событий, все варианты PvP/щитов/транспорта, реальные моды защиты территории, длительные многопользовательские сессии, все настройки и другие графические пакеты. Для этих областей нельзя честно поставить «100% совпадение» по регистрации, тестам рецептов или одному клиентскому снимку.

## Воспроизведение

1. Запустить `scripts/run_original_scenarios.py` в подготовленном локальном окружении Java 25 / NeoForge 26.1.2.122.
2. Выполнить Gradle `build check runEconomyChecks visualCheckClasses` для Fabric; при подготовленных необязательных зависимостях добавить `-PwithJousting -PwithApotheosis`.
3. Проверить свежие `analysis/phase024-scenario-parity.passed`, `phase024-scenario-differences.json` и журнал серверного набора. Пустой список различий относится к матрице и явным адаптациям выше.
