# Обновление 0.19 — оставшиеся ритуальные эффекты и кэш изображений

Сохраняет возможности [0.18](GAMEPLAY-0.18.md), включая импорт данных NeoForge, JEI и DOOM. Клиент и сервер должны использовать одинаковый JAR 0.19.

## Исправлено

- Восстановлен исходный круг «Чаши небес» на высоте Y=120 с кольцом рун, вращением, цветом и настройкой `HEAVENS_CUP_CLIENT_CIRCLE`. При Y≤2 устранено деление масштаба на ноль. Общий ритуальный renderer снова разрешает отрисовку вне экранных границ блока, как оригинал.
- Восстановлены подписи тревожной границы и списка исключений Drain Life. Подпись извлекается только для владельца; повторное использование состояния renderer не переносит её на чужой ритуал.
- Общие конвейеры текстурированных квадов и полос треугольников объявляют и привязывают используемую стандартным шейдером карту освещения. Проверены видимые кольцо чаши и DOOM.
- Локальный переключатель `MYSTIC_STAFF_EXPLOSION_SOUND` снова отключает исходный звук взрыва через настоящий SoundEngine, не меняя серверные звуки остальных игроков.
- Серверная настройка `POWER_CONSOLIDATION_RETRO_FOG_FIX` восстанавливает индекс блоков старого озера при загрузке чанка и сбрасывает его флаг ремонта. По умолчанию выключена, как в оригинале.
- GIF из дискового кэша декодируется как анимация и восстанавливает сведения о кадрах без доступа к исходному URL. При выходе из мира освобождаются текстуры и метаданные; поздно завершившаяся загрузка закрывает изображение вместо повторной загрузки закрытой текстуры. Общая таблица GIF безопасна при обращении из потока загрузки. Распознаются заголовки GIF87a и GIF89a. Декодированные кадры и атлас ограничены 16 мегапикселями; заведомо чрезмерный размер отклоняется до создания кадра.

## Проверки

Серверные проверки включают реконструкцию настоящего чанка озера: выключенный ремонт не меняет индекс, включённый находит блоки, повторный вызов не повторяет сканирование. Полный игровой набор, включая 53 семейства и DOOM, запущен в `analysis/phase019-final-checks.log`.

В настоящем клиенте проверяются зарегистрированный renderer чаши, две дополнительные геометрические отправки, конечные матрицы при низком Y, подпись только владельца и переключение реального SoundEngine. Кэш GIF проверяется с недоступным сетевым адресом: цвета двух кадров сравниваются с UV анимации. Отдельно проверяется завершение загрузки после закрытия текстуры. Результаты — `analysis/phase019-client-checks.txt`.

Кадры в `docs/screenshots/0.19-*` показывают чашу, обе подписи и DOOM. Это проверка Fabric, а не новое попиксельное сравнение с клиентом оригинала.

Готовый JAR отдельно запускается дважды на копии мира NeoForge с Fabric API, без служебного кода и JEI: `analysis/phase019-release-world.passed` фиксирует результат и SHA256 конкретного JAR.

## Остающиеся ограничения

Сборка по-прежнему INCOMPLETE: полная матрица всех заклинаний, поз и изображений не сопоставлена с оригиналом, Sodium/Iris и длительная нагрузка не подтверждены. Проверка GIF не означает проверки всех вариантов disposal/задержек, сбоев HTTP и перезагрузок ресурсов. Jousting и Apotheosis для данной версии доступны в проверенном каталоге как NeoForge-моды; их внешние API в обычном Fabric не подключены. Исходные неактивные переключатели не добавляются как фиктивно работающие настройки. Не поддерживаемые нестандартные параметры при подготовке мира по-прежнему отклоняются.
