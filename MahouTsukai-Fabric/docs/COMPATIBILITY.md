Основной серверный набор использует Fabric API и текущий порт; клиент дополнительно проверен с JEI и отдельно с Iris/Sodium/Complementary. Отсутствие ошибок
на таком стенде не доказывает совместимость с пользовательским набором модов.
Точные версии установленных серверных модов и их конфиги не предоставлены.
