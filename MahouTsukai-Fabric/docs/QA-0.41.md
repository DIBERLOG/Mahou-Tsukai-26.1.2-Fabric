# Меню паузы — 0.41

Minecraft 26.1.2 / Fabric / Java 25. Изменён только заголовок полного меню паузы: **MAHOU TSUKAI**, наклонная подпись **Fabric port**, два красных рунических круга. Картинка — прозрачный PNG; фон игрового мира остаётся обычным. Кнопки не перемещаются.

Используются штатные события экранов Fabric и обычный ресурс текстуры. Новые зависимости, сетевые пакеты и изменения боевой логики не добавлялись. Ресурс можно заменить клиентским или серверным ресурспаком: [инструкция](PAUSE-MENU-BRANDING.md).

## Проверено

- `build visualCheckClasses --offline --console=plain`: **BUILD SUCCESSFUL**.
- Настоящий клиент 0.41 подключён к локальному выделенному серверу 0.41.
- Восемь нативных вариантов меню/повторного изменения размера при запрошенных GUI scale 1–4: прежний заголовок скрыт, кнопки и подписи сохранены, прямоугольник логотипа не пересекает кнопки и не выходит за ширину экрана. Фактический масштаб ограничивается обычными минимальными размерами интерфейса Minecraft.
- Компактная пауза без полного меню сохраняет свой текст. PNG загружается настоящим менеджером ресурсов и содержит прозрачные и непрозрачные пиксели.
- Шаблон ZIP принят настоящим репозиторием ресурспаков. После перезагрузки текстура разрешается именно из этого ZIP; прежний набор ресурсов восстановлен и успешно загружен повторно.
- Оформление просмотрено в игре; [снимок меню](screenshots/0.41/pause-menu.png).

В этой итерации боевые сценарии 0.40 повторно не запускались: их исходники не менялись. Доставка ресурспака удалённому клиенту через интернет не проверялась; локальное применение ZIP и восстановление ресурсов проверены настоящим клиентом.
