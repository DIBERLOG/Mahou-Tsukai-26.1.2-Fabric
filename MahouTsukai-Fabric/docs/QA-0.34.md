# Архимаг: вертикальный посох и бой — 0.34

Minecraft 26.1.2 / Fabric Loader 0.19.5 / Fabric API 0.155.3+26.1.2 / Java 25. Предыдущие пользовательские изменения сохранены; публикации на GitHub не было.

Изменения:
- Посох прикреплён внутри правого кулака и сохраняет вертикальную ось при ходьбе, подготовке магии и парении. При ударе посохом и падении допускается намеренный наклон.
- Десять настоящих анимаций, включая новые `golden_volley` и `summon_vex`. Пять видов атак имеют отдельные позы и общую подготовку 32 тика (1,6 секунды).
- Клыки заклинателя: до 16 настоящих EvokerFangs, последовательно выходящих из земли с принадлежностью Архимагу.
- Каменные столбы: шесть временных отображаемых колонн из глубинного сланца поднимаются за 12 тиков, наносят удар при подъёме и исчезают. Это геометрия BlockDisplay, без физической коллизии и изменения блоков мира.
- Огненный залп: три настоящих снаряда с золотистым следом. Нативные столкновения/урон, без разрушения блоков и размещения огня. Собственный хозяин и его союзники защищены от взрыва.
- Ударная волна: расширяющееся золотое кольцо наносит урон каждому существу один раз; его можно перепрыгнуть. Отклонённый урон не вызывает отбрасывание.
- Призыв: максимум три принадлежащие Архимагу вредины с ограничением 200 тиков; удаляются при смерти/выгрузке хозяина.
- Звуки голоса, ранения, смерти и подготовки взяты у стандартного заклинателя. Добавлены три оригинальных синтезированных звука подготовки, выпуска магии и ударной волны — реальные mono OGG 32000 Гц (0,9/0,45/1,3 с).

Проверки именно этой версии:
- `runProgressionChecks runEconomyChecks runAuditFixChecks build visualCheckClasses`: BUILD SUCCESSFUL, `analysis/phase034-delivery-checks.log`.
- `ARCHMAGE_COMBAT_034`: настоящие 32 тика подготовки, все 5 атак, урон клыками и попадание снарядом по настоящим существам, срок жизни и отсутствие разрушения блоков у столбов, однократная волна/прыжок/отказ урона, предел вредин, очистка по точному владельцу после удаления/загрузки. Нативные фиктивные игроки подтверждают загрузку клиента, поэтому проверки HP используют штатный hurtServer.
- Новый проверочный игрок для прыжка создаётся после испытания снарядов: ранние попадания не должны загрязнять его здоровье перед отдельной проверкой волны.
- Старое ожидание строго пустой цели заменено правильным контрактом: дальняя цель отбрасывается; немедленно выбранная другая цель допускается только живой, внутри той же арены и измерения.
- `archmage-model-check` в Minecraft:50 кубоидов,10 разных анимаций/410 конечных промежуточных поз,3 непрерывных цикла,384 смешанные позы с вертикальным посохом и успешное декодирование 3 новых звуков.
- Валидация `.bbmodel`:50 кубоидов,10 групп,615 ключевых кадров,300 граней без UV-пересечений,2807 измерений оси посоха, максимальный наклон в отдельной исходной дорожке 0,313°. Нативная компенсация после смешивания удерживает ось точнее.

Тестовый бой подготовлен в отдельной арене около 1280/300/1280 в локальном progression-preview, вдали от деревни. Снаряжение находится в бочке у входа, текущие предметы игрока не заменяются. Для боя включается сохранение инвентаря после смерти и устанавливается точка возрождения у входа; исходные сведения игрока сохраняются локально в `analysis/archmage034-battle-context.json`.

Не заявляется завершённым: проверка открытия проекта в самом Blockbench (браузерный доступ ранее отклонён), полноценный бой нескольких живых клиентов, все сторонние моды и шейдеры. Новый обычный бой запускается для самостоятельной проверки пользователем. Предыдущие незавершённые визуальные переделки остальных заклинаний не считаются выполненными этой работой.
